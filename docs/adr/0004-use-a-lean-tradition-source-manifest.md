# Use a lean tradition-source manifest

The repository keeps one lean source manifest with nested identity, edition, authority, provenance, rights, and corpus-membership fields rather than implementing a full library catalog. It preserves the useful bibliographic distinctions between a conceptual work, its exact edition, the retrievable artifact, and a tradition body's recognition, but creates separate records only when one of those facts actually varies. This keeps citations and authority honest without making cataloging infrastructure part of the product.
