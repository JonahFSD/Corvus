# Model source authority within each tradition

The tradition corpus records a source's authority relative to the named tradition that recognizes it rather than assigning every source a universal rank. Recognition uses shared controlled fields for source kind, recognizing-body level, geographic scope, reception state, and binding extent; normative status is tradition-namespaced and accompanied by the recognizing body's own cited authority claim. Answer logic may compare positions, but no numeric rank or equivalence crosswalk may imply that unlike authorities occupy the same level.
